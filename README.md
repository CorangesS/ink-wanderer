# 墨野行 · Ink Wanderer

水彩 / 水墨风格的 2.5D H5 生存游戏。原生 Canvas + HTML/CSS/JavaScript，无框架、无安装依赖、无在线接口。

## 在线试玩

[打开《墨野行》](https://corangess.github.io/ink-wanderer/)

## 开始游戏

直接用浏览器打开 `index.html`，或在本目录运行：

```sh
python3 -m http.server 8876 --bind 127.0.0.1
```

然后访问 http://127.0.0.1:8876 。建议横屏体验；手机竖屏提供摇杆和闪身按钮。

## 操作

- WASD / 方向键：移动。
- 自动瞄准攻击附近敌人。
- 空格：闪身，短暂无敌，3 秒冷却。
- Esc：暂停 / 继续；失去窗口焦点时自动暂停。
- 手机：左侧摇杆移动，右侧「闪」闪身。
- 右上角喇叭：开启 / 关闭轻音乐与合成音效；默认静音。

## 一局修行

六波战斗，每波 35–60 秒。击败墨灵后靠近拾取灵墨，同时获得经验与货币。升级时从三项感悟中选一。波次结束收取遗落灵墨，回复 20% 生命，可在山间小憩中购买笔法、属性或刷新选项。最后一境击败墨魇即可通关。

笔法包括青竹笔的自动墨锋、飞白剑的环绕剑阵与墨莲的定时范围伤害；另有生命、回复、攻速、移动、会心成长。墨灵有普通、冲刺、重甲、远程与首领类型。最佳散墨数、最高境和通关次数保存在浏览器本地。

## 美术与实现

`assets/landscape.png`、`assets/wanderer.png` 与 `assets/ink-spirits.png` 使用内置 imagegen 生成；完整提示词见 `ART_PROMPTS.md`。背景、行者与墨灵为原创水彩素材，剑阵、墨锋、飘叶、墨迹、波纹与纸张纹理由 Canvas/CSS 绘制。角色按脚底位置排序，结合地面投影、前景树木遮挡和移动镜头形成 2.5D 层次；并非 3D 建模游戏。

所有资源位于本目录，可整体复制或部署为静态网站。

## 部署

通过 GitHub Pages 免费托管，发布源为 `main` 分支根目录。更新游戏文件并推送到 `main` 后，GitHub 会自动重新发布。`.nojekyll` 用于直接发布静态资源，不需要构建。
